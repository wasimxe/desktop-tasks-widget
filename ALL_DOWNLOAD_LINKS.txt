TO DOWNLOAD:

1. Find the downloaded file (usually in Downloads folder)

   - Transfer via USB drive to this computer

Option 3: Use Visual Studio Community (link #13)
   - This is a full IDE that includes .NET SDK
   - After installing Visual Studio, the .NET SDK will be available
